縦＝中に含む（子房 ↓ 胚珠）／ 横＝対比・並列（被子 ⇄ 裸子）／ 真ん中＝対比語句の親カテゴリ（子葉2枚 ─ 子葉 ─ 子葉1枚）
📝 説明文（語句のつながりをそのまま読み上げる） 植物 がつくるものは 種子 と 胞子・胞子のう。種子をつくるのが 種子植物、胞子を 胞子のう でつくるのが 種子をつくらない植物。
種子植物 は 被子植物 と 裸子植物 に分かれる。被子植物 は 花 を咲かせ、外側から順に がく・花弁・おしべ・めしべ。花弁 が1枚ずつ分かれているのが 離弁花、つながっているのが 合弁花。おしべ の先端の やく に 花粉。めしべ のふくらんだ部分の 子房 の中に 胚珠、先端は 柱頭。裸子植物 は 子房 がなく 胚珠 がむき出し。
被子植物 はさらに 双子葉類 と 単子葉類 に分かれる。子葉 は2枚 ⇄ 1枚、葉脈 は 網状脈 ⇄ 平行脈、根は 主根から側根 ⇄ ひげ根。
種子をつくらない植物 は シダ植物 と コケ植物 に分かれる。シダ植物 は 葉・茎・根 の区別あり。コケ植物 は区別なく、かわりに 仮根 でからだを支え、雄株 と 雌株 に分かれる。
